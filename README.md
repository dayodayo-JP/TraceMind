# TraceMind - 可視化
Dockerコンテナ監視のツール。メモリの一ビットからコンテナ間通信の各パケットまで、遍く全てを漏らさず監視する。デバッグや動作速度の改善からセキュリティテストまで、様々な用途に使っていただきたいと思う。

①監視内容
(1)CPU/GPU/NPUその他の演算装置
・使用率
・キャッシュヒット率
(2)メモリ
・バイナリ
・メモリ占有率
(3)ストレージ
・書き込み量と速度
・読み込み量と速度
(4)入出力
・コマンド入力その他全ての入力
・出力
(5)ネットワーク
・他コンテナとの通信のパケット
・外部との通信のパケット
②環境
MCPあるいはコマンドプロンプト
